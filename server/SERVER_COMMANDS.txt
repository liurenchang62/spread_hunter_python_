# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# ① 不经 GitHub：按本机 Git 状态直传服务器（密码用环境变量）
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
#
# 本机先安装：pip install -r server/requirements.txt
#
# 环境变量（Windows 可在「系统环境变量」里设置，或当前会话）：
#   SERVER_PASSWORD     — 必填，SSH 登录密码（脚本内自动填入，无需交互）
#   SERVER_HOST         — 可选，默认与下项相同
#   SPREAD_HUNTER_SERVER — 可选，未设 SERVER_HOST 时用（默认 45.76.202.248）
#   SERVER_USER         — 可选，默认 root
#   SERVER_REMOTE         — 可选，默认 /root/spread_hunter_python
#   SERVER_PORT           — 可选，默认 22
#
# 模式说明：
#   --mode all     — 与「git 跟踪的改动 + 未跟踪且未被 ignore 的文件」一致，
#                    并在远程删除「相对 HEAD 已删除且非 ignore」的路径（与本地工作区对齐）。
#   --mode ignored — 上传被 ignore 的「机密与本地配置」（默认会跳过 .venv、__pycache__、
#                    logs/、tools/out/ 等；与旧 scp 脚本意图一致）。若确需连虚拟环境等
#                    一并镜像，请加：--full-ignored
#                    上传后会对 api_keys* / withdrawal_addresses、env/.env 做 chmod。
#
# 在仓库根目录（PowerShell / cmd 均可）：

python server/sync_to_server.py --mode all
python server/sync_to_server.py --mode ignored

# 仅打印将执行的操作：
# python server/sync_to_server.py --mode all --dry-run

# 仍可用 SSH 密钥 + scp 的旧脚本（不上传 SERVER_PASSWORD；需本机已配好密钥）：
# powershell -ExecutionPolicy Bypass -File .\server\sync_secrets_to_server.ps1
# powershell -ExecutionPolicy Bypass -File .\server\sync_secrets_to_server.ps1 -Server "你的IP"
